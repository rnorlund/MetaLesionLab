# Replication at n = 100: pre-registered plan

Written **Oct 27, 2026**, before any lesion was run on the new pictures. It is committed before the
first lesioned run, and the commit is the timestamp. Results go in `docs/replication.md`.

## Why

The findings so far rest on **20 pictures** per language (`demo_en`, `demo_es`, `demo_fr`, `demo_pt`).
At n = 20, one picture moves accuracy by 5 points. This plan reruns the key findings on **100 new
pictures** with the same doses and the same measures, and says in advance what counts as replicated.
If an effect shrinks or vanishes, that is the result.

## Pictures

- **Word list:** `scripts/wordlists/core100.json` (the English list for Test Studio is
  `core100_en.txt`). 100 concrete nouns in nine categories, plus four other objects:
  - 12 animals, 10 tools, 11 foods, 12 household objects, 10 vehicles, 10 body parts, 11 nature
    items, 10 musical instruments, 10 clothing items, 4 others;
  - English Zipf frequency from 2.6 (igloo) to 5.7 (house): 17 below 3.5, 54 from 3.5 to 4.5, and
    29 at 4.5 or above;
  - all 20 demo words are included, so per-word comparisons with the old runs are possible.
    Their pictures are **new drawings**: every picture in the set is new.
- **English set** `core100_en`: built by Test Studio (`scripts/build_test_set.py`): Muse Image draws
  two line drawings per word, SAM 3.1 and Muse Spark check them, and the best passing drawing is
  the test picture. **The other drawing is held out** and is used only for localizers and reference
  statistics, never as a test picture.
- **Visual review:** the contact sheet is checked by eye before any GPU run. Pictures that are
  wrong, ambiguous or hard to draw are fixed (redrawn) or dropped, and every drop is recorded in
  `docs/replication.md` with its reason. No picture is dropped or changed after the first GPU run.
- **Spanish, French and Portuguese sets** `core100_es`, `core100_fr`, `core100_pt`: the **same
  pictures** (no new images), named from the word table (`scripts/language_sets.py`). This is what
  the bilingual test needs: the same pictures in every language.
- **Accepted names** are in the word table: the target, then alternates chosen on one principle in
  every language (synonyms, regional names, short forms, spellings). As in the first run, accepted
  names may be added after the **intact** pilot, on the same principle in every language, and are
  frozen before the first lesioned run. English spellings are not accepted in other languages
  (`metalesionlab/bilingual.py`).

## Model and scoring

Unchanged from the first run:

- Muse Glimmer 30B, decoder in FP8, one NVIDIA L40S, greedy decoding, 12 new tokens, batches of 10.
- Coding: `naming_errors.classify` on the first attempt, carrier phrase removed. **No Muse Spark
  meaning judge** in any primary measure. English meaning relations come from WordNet only.
  "Correct" never depends on a judge.

## Reference statistics and localizers

- **Reference statistics:** the same recipes on the new held-out drawings.
  - Model Lab, English: `core100_en` held-out drawings, English naming prompt.
  - Model Lab, Spanish: the same drawings, Spanish naming prompt (`core100_es`).
  - Bilingual test: pooled over the held-out drawings × the four language prompts, plus the
    English-only and Spanish-only statistics for the robustness check.
- **Localizers** (`scripts/model_lab.py localize`):
  - `naming_c100`: naming vs. yes/no verification, on the 100 held-out `core100_en` drawings.
  - `visual_c100`: intact vs. tile-shuffled picture, same drawings.
  - `language_c100`: sentences vs. scrambled words. Text only, so it doesn't depend on the
    pictures; it is rerun to check it matches `language_en`.
  - The **original** localizers (`naming_en`, `visual_en`, `language_en`, built from the 20 held-out
    `demo_en` drawings) are also applied to the new pictures, as a secondary test.

## Conditions

All doses come from the existing `demo_en` runs. **Nothing is tuned on the new pictures.** The exact
condition lists are generated by `scripts/replication_specs.py` into `scripts/replication/*.json`.

### A. Intact naming

`core100_en` (English Model Lab prompt) and `core100_es` (Spanish Model Lab prompt).

### B. Featured localizer lesions with random-unit controls (`featured_en.json`, 48 conditions)

Mean ablation at the stored fractions of the featured Model Lab conditions:

| Lesion | Fraction of units |
|---|---|
| Naming localizer, MLP neurons | 0.2973 |
| Visual localizer, MLP neurons | 0.2548 |
| Language localizer, MLP neurons | 0.3173 |
| Naming localizer, attention heads | 0.4042 |

- Each lesion is run with the **new** localizer (primary) and the **original** one (secondary).

- The 8 robustness conditions with English-only and Spanish-only statistics.
- The same five variants: English, Spanish, French, Portuguese, and Spanish asked in English.

## Pictures in each measure

- **Model Lab lesion measures:** pictures named correctly by the intact model in that set.
  Accuracy on all pictures is also reported.
- **Bilingual primary measure:** pictures named correctly intact in both languages (as before).

## Primary measures and what counts as replicated

All 95% CIs are percentile bootstraps over **pictures**. Where a condition has several seeds, the
seeds are resampled within the condition. The n = 20 data are reanalyzed with the same code, so old
and new numbers come with the same kind of interval.

### 1. Targeted vs. random damage, per localizer

- **Measure:** Δ = accuracy under the random-unit controls (mean of 5 seeds) − accuracy under the
  targeted lesion, paired by picture.
- **First run (n = 20, raw accuracy):**

  | Localizer | Targeted | Random |
  |---|---|---|
  | Naming | 0.55 | 0.80 |
  | Visual | 0.40 | 0.95 |
  | Language | 0.45 | 0.95 |
  | Naming heads | 0.55 | 0.90 |

- **Replicated** for a localizer if Δ > 0 and its 95% CI excludes 0 with the **new** localizer.
  The original localizer on the new pictures is reported beside it as a secondary test.

### 2. Bilingual: the extra drop outside English

- **Measure:** (intact − lesioned accuracy in the language) − (intact − lesioned accuracy in
  English).
  - Same pictures, pictures correct intact in both languages.
  - Averaged over the 41 main conditions and their seeds.
  - Sign-flip permutation test over pictures.
- **First run:** Spanish +0.28 [+0.23, +0.32], French +0.33, Portuguese +0.35, Spanish with the
  English instruction +0.30.
- **Replicated** for a language if the extra drop is > 0 and its 95% CI excludes 0.
- We also report whether each n = 100 estimate falls inside the n = 20 CI, i.e. whether the size of
  the effect held up and not only its sign.

### 3. Falling back to English

- **(a) Bilingual.**
  - **Measures:**
    - The share of lesioned non-English trials whose first attempt is in English. First run: 23.8%
      for Spanish.
    - The stricter share that is the picture's English name. First run: 11.0% for Spanish.
    - The reverse, the picture's name in another language on English trials. First run: 0.1%.
  - **Replicated** if, for Spanish, French and Portuguese, the English-name share's 95% CI lies
    entirely above the reverse share's CI.
- **(b) Model Lab, Spanish.**
  - **Measure:** under the naming-localizer MLP lesion on `core100_es`, the share of trials whose
    first attempt is in English (`bilingual.language_of`), compared with the 5 random controls.
    Δ is paired by picture. First run: "The object is a cat" for *gato*.
  - **Replicated** if the targeted share is higher than the random-control share and the CI of the
    difference excludes 0 (new localizer).

### 4. Error-type profile per damage site

- **Pooling:** each site's errors are pooled over its dose series and seeds (C above). Shares are
  computed among error trials.
- **Error types:**
  - **Meaning errors:** Semantic + Mixed, from WordNet. Examples: teapot for kettle, scaffolding for
    ladder.
  - **Sound errors:** Nonword + Formal. Examples: "Umb", "Caraloon".
  - **Self-corrections:** the first attempt is wrong, but the answer names the target later
    ("Caraloon? Wait object is carrot"). This is computed per trial, among errors.
  - **Jargon:** Neologism, or a first attempt in which letters are under half of the non-space
    characters ("5-01-26-01-01-01-", ": 2025-2025-2025").
- **Predictions, from the n = 20 descriptions:**
  - **Vision tower:** the largest share of meaning errors of the three sites.
  - **Layers 40–47:** the largest share of sound errors and of self-corrections.
  - **Layers 0–7:** the largest share of jargon.
- **Replicated** for a site if its predicted share is larger than at both other sites and the CI of
  each difference excludes 0. Profiles at the featured doses alone are reported too.

### 5. Secondary: the English pivot in the word lens

- **Measures:**
  - On intact Spanish, French and Portuguese trials, the share of testable pictures whose English
    name is the lens's top guess at some layer before the target takes over. Pictures whose English
    and target names share a first token can't be tested.
  - The layer where the mean English probability peaks.
- **First run:** 15/15, 14/15 and 14/15, with the peak at layers 39–40.
- **Replicated** if at least 80% of testable pictures show it in each language.

## Not part of this plan

- Muse Spark meaning-judge recodes. They may be reported descriptively, not as a test.
- The other `demo_en` conditions: other fractions, zero lesions, the projector.
- "What can I cut?" and Plato's Chair.

## Multiple comparisons

About 15 primary tests (4 localizers, 4 language variants, 4 fallback tests, 3 sites). Each is
judged by its own 95% CI, without correction. The results page reports all of them, including any
that fail.

## Commands

```bash
# Pictures (Mac)
python scripts/build_test_set.py core100_en en scripts/wordlists/core100_en.txt
python scripts/language_sets.py core100 --spark
python scripts/replication_specs.py

# GPU (Axon, ~/MetaLesionLab, env ~/mll-env, PYTHONPATH=$PWD)
python scripts/model_lab.py agreement runs/sets/core100_en
python scripts/model_lab.py agreement runs/sets/core100_es
python scripts/model_lab.py stats runs/sets/core100_en
python scripts/model_lab.py stats runs/sets/core100_es
python scripts/model_lab.py localize runs/sets/core100_en --contrast naming --name naming_c100
python scripts/model_lab.py localize runs/sets/core100_en --contrast visual --name visual_c100
python scripts/model_lab.py localize runs/sets/core100_en --contrast language --name language_c100
python scripts/model_lab.py batch runs/sets/core100_en scripts/replication/featured_en.json --skip-done
python scripts/model_lab.py batch runs/sets/core100_en scripts/replication/components_en.json --skip-done
python scripts/model_lab.py batch runs/sets/core100_es scripts/replication/featured_es.json --skip-done
python scripts/bilingual_run.py stats --prefix core100 --out runs/bilingual_core100
python scripts/bilingual_run.py pilot --prefix core100 --out runs/bilingual_core100
python scripts/bilingual_run.py ids   --prefix core100 --out runs/bilingual_core100
python scripts/bilingual_run.py run   --prefix core100 --out runs/bilingual_core100   # --only to split

# Analysis (Mac)
python scripts/bilingual_analyze.py --prefix core100 --dir runs/bilingual_core100 --boot 10000
python scripts/replication_analyze.py
```
