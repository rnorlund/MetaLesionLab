Ask the Lab

Ask a question in plain language. A Muse Spark agent plans, runs the lab’s tools over results we have already measured, and answers with numbers you can check. Every step is shown.

How it works

  1. Plan. Muse Spark reads your question and picks tools, at most six per question.
  2. Run the tools. Each tool reads results the lab has already computed: lesioned Glimmer’s answers and error types, the word lens, layer removal, the bilingual test, Plato’s Chair and published group data. No GPU runs while you wait.
  3. Answer. The agent may only use numbers from the tool results, and cites a tool for each one.
  4. Check. Before you see it, every number in the answer is matched against the tool results; anything that doesn’t match is flagged.

Research and teaching use only. Ask the Lab answers questions about the AI model and published group studies. It doesn’t give medical advice, and it won’t answer questions about a particular person’s health; a speech-language pathologist or a doctor can. Questions are sent to the Meta Model API to be answered and aren’t stored by this site.
