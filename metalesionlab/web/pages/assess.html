Naming Assessment gives a timed picture-naming test. It records each answer, measures naming latency, transcribes and codes the response, and builds a session report you review and export. It also tracks change across sessions. For use by clinicians and researchers. Measurements only; no diagnosis or prognosis.

New session

20 s as in the Philadelphia Naming Test. Reaching the limit counts as no response.

Privacy and approvals

Each answer's audio is sent to the Meta Model API (Muse Voice Transcribe) for transcription. This app processes it in memory and stores nothing about the person. Results stay in this browser (IndexedDB) until you export or delete them. Get your institution's approval before using this with patients.

    How a session works

    1. Choose a test, a speaker code and the time limit, then press Start session and allow the microphone.
    2. Each picture fills the screen. Recording starts just before it appears. Press Space, → or tap Next when the person has answered; at the time limit it moves on by itself.
    3. Every answer is timed (picture onset to speech onset), transcribed with the test's language as a hint, and coded by the first complete response. Muse Spark can act as a second rater.
    4. Review the codes and latencies, then export the PDF report and the CSV. Sessions are kept per speaker code in this browser for tracking.

    For use by clinicians and researchers. Measurements only; no diagnosis or prognosis. Coding follows the Philadelphia Naming Test categories (Roach et al., 1996), simplified for automatic use. Published reference values are group results on a different test, shown for context.

    Import a test

    Bring a picture-naming test you are licensed to use: a ZIP file or a folder holding the pictures and a CSV with these columns.

    file,target,alternates,practice
p1.png,house,home,yes
01.png,cat,kitty;puss,
02.png,umbrella,,

    file is the picture's file name; target the expected name; alternates other accepted names, separated by ;; practice marks practice items (given first, not scored). For a test that comes as a PowerPoint, such as the Philadelphia Naming Test obtained from its publisher, first run scripts/import_pptx_test.py (see the README).

    A private set is kept only in this browser. Its pictures are never uploaded: during a session only each answer's audio and the target word go to the server.

    Make a test from a photo

    Use a photo of the person's home or belongings, with no people in it. Muse Spark lists the objects it can clearly see, in the test's language; SAM 3.1 finds each one; Muse Image redraws it as a line drawing in the same style as our sets (or it is cropped from the photo). Then the usual Test Studio checks run.
