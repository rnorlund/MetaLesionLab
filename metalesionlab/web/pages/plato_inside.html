Inside the model

Plato thought every chair copies one ideal chair. We gave Meta’s open model Muse Glimmer the doodles from Plato’s Chair, Muse Image’s and people’s, and read its state after each of its 52 layers. First it sees a drawing. Layer by layer, it settles on a name.

Muse Image’s doodles of a thing arrive at one idea: by the naming layers they sit almost on one point. People’s doodles never do.

    Method and caveats

    • Pictures. 35 things from Plato’s Chair: every Muse Image doodle (16 for 10 things, 12 for 25) and the same number of people’s doodles from Google’s Quick, Draw! game, 920 pictures in all, each padded to a white square at 448 px.
    • States. Muse Glimmer 30B, Meta’s open-weight model on our own GPU, read each picture with the prompt “Name the object in this picture with exactly one word.” We kept its state (6,656 numbers) at the answer position after each of its 52 layers.
    • Spread. The average cosine distance between two doodles of a thing from the same source, on states centered over all 920 pictures: 0 would be one point. This is the measure of the main Plato’s Chair experiment, and the chart uses all 6,656 numbers.
    • The collapse layer is a convention. It is the first layer from which Muse’s doodles stay less than half as spread out as people’s through layer 52. We chose the 0.5 after seeing the data, not before.
    • The word lens reads names, not concepts. It applies Glimmer’s output layer to each layer’s state (a logit lens). The layer where it first reads the name shows when the name becomes readable there, not when the idea of a chair forms. Early layers aren’t tuned to the output layer, so the lens says little about them.
    • The answer position. In the middle layers this position carries little about which thing a doodle shows, so spread there is mostly not about the thing. In the last layers it partly is the answer itself.
    • Drawing style. Muse Image’s doodles are clean marker sketches; people’s are 20-second mouse or finger drawings, often unfinished. Part of people’s spread is skill and noise.
    • Person. Quick, Draw! has no “person”, so both sides drew yoga; Glimmer often answers with pose names (“Tree pose”, “Meditation”).
    • Exploratory. 35 things, 12–16 doodles per source, one model, one prompt, one picture size. Nothing here was pre-registered.
